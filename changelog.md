# Tinkers' Compatibility Changelog

## 2.1.0

## Additions:
- Added flavour text for all materials.
- Added melting recipes for Ad Astra plates.
- Added translations for Alternative Vines & Dragonscale tags.
- Craftable modifiers are now tagged properly.
- Ad Astra ores now have proper ore melting recipes.
- Desh now has the new "Discharge" trait.
- Ostrum now has the new "Cryogenic" trait.
- Added an optional built-in resource pack with sprites for extra addon integration.
- Added the Dart Shooter as a modifiable tool.
- Added unique parts for Dart Shooters.
- Added integration with Create:
  - Materials:
    - Brass (Clockwork Trait)
  - Modifiers:
    - Wrenching (Harvest primary)
    - Goggles (Helmets)
  - Recipes:
    - All metal blocks and items can now be melted in the smeltery.
    - Chocolate Bars can now be melted in the smeltery.

## Changes:
- EMI is no longer compiled as it is only needed during runtime testing.
- "regions_unexplored:kapok_vines" & "biomesoplenty:willow_vine" can be used to craft normal vine parts.
- Added the following vine materials/variants:
  - Betternether:
    - Black Vine | Variant of Weeping Vine
    - Golden Vine
    - Blooming Vine
  - Betterend:
    - Twisted Vine | Variant of Twisting Vine
    - Jungle Vine | Variant of Twisting Vine
    - Bulb Vine
    - Dense Vine
  - Biomes We've Gone:
    - Skyris Vine | Variant of Vine
  - Aether Redux:
    - Corrupted Vine
    - Golden Vine
  - Deep Aether
    - Yagroot Vine
  - Deeper & Darker
    - Sculk Vine
- Blighted now works for melee and thorns damage.
- "blightbunny_fang" & "mykapod_shell" now have the correct load conditions.
- Tweaked Glaive stats:
  - Base Attack Speed: 1.0 -> 1.1
  - Durability Multiplier: 1.5 -> 1.2
  - Melee Sweep Range: 3.0 -> 4.0
  - Attack Damage Multiplier: 1.5 -> 0
- Un-Deprecated Zanite & Skyjade materials.
- Nether Ruby now uses the proper gem material recipe method.
- Storage blocks for the niche Malum materials can now be used to craft parts.
- Gravitite now supports Bow Limbs & Bow Grips.
- Ascension now floats entities struck by a projectile.
- Pyral ranged parts should now be obtainable.
